# Tmall CSV Auto Filler

一个手写 Web UI（Flask + HTML）工具，功能如下：

1. 上传 CSV 文件。
2. 读取 `订单号` 列。
3. 直接控制已打开、已登录的有头 Firefox：在同一窗口新建临时标签页访问订单详情并读取已渲染内容（不启动新 Firefox 进程）。
4. 抓取 `快递单号` / `到达时间` / `物品简述` / `付款时间`（多策略提取）。
5. 将抓到的 `付款时间` 自动补到 `购买时间` 列（仅当该单元格为空时）。
6. 仅补全空白单元格，不覆盖原有内容。
7. 提供补全后 CSV 下载按钮。

## 环境准备

```bash
pip install -r requirements.txt
```

## 启动

```bash
python app.py
```

打开浏览器访问：`http://127.0.0.1:5000`

## 使用前要求

- 必须先打开 Firefox 并登录淘宝/天猫；程序不读取 Cookie 文件，也不使用 HTTP 直连。
- 执行期间 Firefox 必须保持可见、未最小化且 Windows 未锁屏；请不要操作键盘或鼠标。
- 程序仅在现有 Firefox 窗口内创建一个临时标签页，结束时自动关闭它。
- 每个订单只会在地址栏打开一次详情 URL，固定等待页面加载后，用键盘复制一次已渲染正文；不会点击订单页、物流、确认收货或其他页面元素，也不会轮询或重试同一个订单。
- Web UI 默认每页等待 20 秒、两单之间固定等待 20 秒；可在页面上增加等待时间（最少 10 秒）。
- 若 Firefox 显示“访问受限”或“操作频繁”，程序会立即停止后续订单，不会继续请求。
- 如果抓取不到某条订单信息，该行会保持原值不变。
- 程序只会写入空白值（空字符串、`nan`、`/`、`\\` 等会视为空）。
